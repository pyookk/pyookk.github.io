Ketik kode room dari pasanganmu

Supaya bisa main berdua
  1. Kalian berdua masuk ke akun Claude di HP masing-masing (buka claude.ai di browser atau aplikasi Claude).
  2. Pemilik game membuka menu Share di game ini, lalu mengundang email akun Claude pasangannya.
  3. Pasangan membuka game dari undangan itu, bukan dari link publik, lalu pilih Main Berdua → Gabung.
Kalau dibuka tanpa akun atau lewat link publik, game tetap bisa dimainkan dengan Main Sendiri.
