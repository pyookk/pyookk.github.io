# Pyookk

Masak kue rame-rame, jangan sampai gosong!

Game masak cepat-cepatan bertema toko kue. Bisa dimainkan sendiri, berdua, atau rame-rame sampai 4 orang dari HP masing-masing lewat kode room, tanpa akun apa pun.

Main di: https://pyookk.github.io/
