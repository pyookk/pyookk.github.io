# Pyookk

Masak kue rame-rame, jangan sampai gosong!

Game masak cepat-cepatan bertema toko kue. Bisa dimainkan sendiri, atau berdua dari HP masing-masing lewat kode room, tanpa akun apa pun.

Main di: https://ranggaramadhan86jambi.github.io/pyookk/
